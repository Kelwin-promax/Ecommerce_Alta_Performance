# 🚀 E-commerce de Alta Performance (Fullstack)

Este é um projeto de e-commerce "Headless" desenvolvido do zero para garantir máxima performance, utilizando **React** no frontend, **Node.js** no backend e **MySQL** como banco de dados.

## 🛠️ Tecnologias Utilizadas

* **Frontend:** React.js + Vite (Build ultra-rápido)
* **Backend:** Node.js (API REST com ES Modules)
* **Banco de Dados:** MySQL (Alta consistência de dados)
* **Comunicação:** Axios & CORS
